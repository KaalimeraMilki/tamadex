# TamaDex V5 — Complétion & lignées

V5 ajoute :
- priorité visuelle aux formes non obtenues dans le TamaDex et l’assistant d’évolution ;
- regroupement « À découvrir » / « Déjà obtenu » ;
- conservation de l’adulte et de toute la lignée ;
- phase adulte « Préparer la génération suivante » ;
- enregistrement du partenaire et du type d’accouplement ;
- nouvelle génération reliée à la précédente ;
- Uni : mise en avant des formes manquantes dont les règles connues mentionnent mariage/Tamaverse/génération ;
- Paradise : continuité de lignée sans confondre génétique et conditions d’évolution.

## Installation
1. Exécuter `tamadex-v5-migration.sql` dans Supabase.
2. Vérifier le résultat final.
3. Déployer ensuite les fichiers frontend sur GitHub Pages.
