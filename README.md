# TamaDex V5.1 — Guide débutant contextuel

Ajoute des boutons `?` aux conditions de l'assistant d'élevage, des fiches « Comment faire / Combien / Quand / Comment compter », un mode débutant dans le profil, et une table `help_topics` modifiable par l'administratrice.

## Installation
1. Exécuter `tamadex-v5.1-migration.sql` dans Supabase.
2. Vérifier le résultat final (nombre de fiches d'aide).
3. Déployer ensuite les fichiers frontend sur GitHub Pages.
