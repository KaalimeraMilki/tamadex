# TamaDex V4 · Paradise

Extension Paradise de TamaDex V4.

## Nouveautés
- Suivi Paradise depuis l'œuf : version de l'appareil + champ courant.
- Arbre Bébé → Enfant pour Terre, Eau, Ciel, Forêt, Tropical et Glace.
- Arbre Enfant → Ado piloté par la majorité alimentaire.
- Arbre Ado → Adulte piloté par les erreurs de soin.
- Sur Paradise, les erreurs de soin sont cumulées depuis le stade Enfant jusqu'à l'adulte.
- Route « soins parfaits » : 0 erreur + faim et bonheur remontés au maximum 5 fois pendant l'Ado.
- Secrets par connexions à deux couleurs/versions différentes.
- Variantes Forest / Tropical / Frozen ajoutées au catalogue de croissance.
- Sélecteurs visuels et boutons de suivi adaptés au champ et aux aliments utiles.

## Installation
1. Avoir déjà installé les migrations jusqu'à TamaDex V4 Uni.
2. Exécuter `tamadex-v4-paradise-migration.sql` dans Supabase.
3. Vérifier le tableau de contrôle final.
4. Déployer ensuite les fichiers frontend sur GitHub Pages.

## Sources de référence
Les règles sont structurées à partir du site officiel Tamagotchi Paradise et de tableaux de croissance communautaires documentés. Les nouvelles variantes 2026 (Orange Tropics / White Glacier) sont incluses.
